# Evidence directory

Codex creates STEP_00.md through STEP_26.md during implementation, plus BASELINE_AUDIT.md when adopting existing work. Do not populate passing results in advance.

Each record includes requirement IDs, platform/toolchain, build commit, exact test commands/results, fixed expected/observed numerical values, manual procedure/results, visual captures when useful, fixture hashes, performance samples when relevant, unresolved issues, and next action.

Do not commit private user projects as test fixtures. Use the deterministic example data in the specifications.
