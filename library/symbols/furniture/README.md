# Furniture SVG folder

Beds, sofas, chairs, tables, desks, wardrobes and shelves. Example bed-double.svg: catalog physical footprint 1800×2000 mm.

Place optional SVG files in this directory and add matching versioned definitions in library/catalog/. Follow docs/10_LIBRARY_AND_SVG.md for viewBox, units, anchors, validation, fallback, and licensing.

Use self-contained 2D paths/shapes. No script, external links, perspective rendering, or missing physical-size metadata. The completed application uses procedural defaults when optional SVG artwork is absent. Existing documents keep their pinned embedded appearance until explicitly updated.
